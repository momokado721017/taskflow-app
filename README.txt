# TaskFlow PWA

TaskFlowをPC・スマートフォンの両方で使える、インストール可能なWebアプリ（PWA）にしたパッケージです。

## 重要：データ保存について
- タスクやスタンプはブラウザの `localStorage` に保存されます。
- **PCとスマートフォンのデータは同期されません。** 同じアプリを両方にインストールしても、端末ごとに別々のデータになります。
- ブラウザのサイトデータを消去すると、保存データが失われる可能性があります。定期的なバックアップ機能は今後追加できます。

## 起動・インストール
PWAのインストールとオフライン機能には、`https://` または `localhost` での配信が必要です。HTMLを直接 `file://` で開くだけではインストール・オフライン機能が有効になりません。

### PCで試す（Pythonがある場合）
1. このフォルダーをPCに展開します。
2. ターミナル／コマンドプロンプトでこのフォルダーへ移動します。
3. 実行：`python -m http.server 8000`
4. 同じPCのブラウザで `http://localhost:8000` を開きます。
5. Chrome / Edge では、アドレスバーのインストールアイコンまたはTaskFlowの「アプリをインストール」を選びます。

### スマートフォンで使う
スマートフォンからも使うには、このフォルダーをHTTPS対応の静的ホスティング先に公開する必要があります。公開後、そのURLをスマートフォンのブラウザで開きます。
- Android / Chrome：メニューから「アプリをインストール」または「ホーム画面に追加」
- iPhone / Safari：共有メニュー →「ホーム画面に追加」

## ファイル
- `index.html`：TaskFlow本体
- `manifest.webmanifest`：アプリ名・表示方法・アイコン
- `service-worker.js`：アプリ本体のオフラインキャッシュ
- `icons/`：アプリアイコン

## 今回の範囲
PWAの土台を追加しました。実際のブラウザ・各端末でのインストール、オフライン起動、保存データの保持は、配信環境でテストしてください。
